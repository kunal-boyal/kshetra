# Field procedures

For field people using the Android app: the role called Field user by default (SME in the agri template, MR in pharma, DSR in FMCG, TSM in building materials), and managers on the days they work in the field themselves. Managers' own screens, the Team tab among them, are in [../manager/](../manager/README.md). The procedures follow the order of a working day: sign in, start the day, follow the plan, visit, fill forms, take orders and money, end the day, then the things you check now and then.

The app works without signal. Almost everything you record is saved on the phone first and uploads by itself; each procedure says what needs a connection. The bottom bar has up to five tabs: **Home**, **Plan**, **Orders** (the tenant's word for orders), **Team** (managers only) and **More**. A tab you have no use for doesn't show.

| [Follow today's plan](todays-plan.md) | Today's plan on Home, the **Plan** tab, adding an unplanned visit | Field user, Manager |
| [Visit an account](visit-an-account.md) | Find an account, check in against its geofence, do the visit's work, check out, propose where it is | Field user, Manager |
