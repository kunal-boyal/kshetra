# EmptyState

An empty state says why there is nothing here, what happens next and who acts — in one or two sentences, with at most one action.

## Rules
- A 72 px IconChip (`xl`) in the hue of what is missing, or else in the accent's tint (`accent-subtle` with `accent-subtle-fg`, so it follows Forest and each tenant's accent, never a fixed pastel), a title in `heading-md` and a sentence in `text-muted`, on a `radius-xl` card. Icons only: no illustrations, no emoji.
- Name the actor ("Your manager has not…"); never blame the user.
- Offer an action only if the viewer can take it (permissions decide), as a `tonal` button.
