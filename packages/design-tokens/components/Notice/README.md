# Notice

A notice states what a figure or record really is — provisional, indicative, dated, a request — directly beside it.

## The consumer provides
One of the required strings from the README's copy table, with placeholders filled. Bold only the date or source.

## Rules
- Placed above or below the thing it qualifies, never in a tooltip or a help page.
- Neutral styling (`surface-sunken`, `text-muted`); it is information, not a warning. On the phone a tone (`info`, `success`, `pending`, `danger`, each its `-bg` with its `-fg`) and an icon may mark news, all being well (an order within credit), something waiting or a problem; in Outdoor it gains an edge in its ink.
- Not dismissible. If it feels repetitive, it is working.
